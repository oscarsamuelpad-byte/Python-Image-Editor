# Python Image Editor

Python Image editor is an application made with the purpose of being an image editor, this is meant to be a proof of concept that image editors do not have to be commercialized.

## Installation

First, download the files from the repository, or clone the repository using the following command in any directory using the terminal:

`git clone https://github.com/oscarsamuelpad-byte/Python-Image-Editor.git`

Before running the program, it is required that Pillow, ttkbootstrap, and tkinter be installed.

**DO NOT RENAME THE ASSETS FOLDER**

## Usage

After proper setup, simply run the proj.py file, ensuring that proj.py and assets folder are in a the root directory.
